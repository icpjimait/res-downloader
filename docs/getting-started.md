## 使用方法
1. **启动软件**：
   - Windows 首次使用建议鼠标右键选择“以管理员身份运行”。
   - 首次启动同意安装证书，并允许网络访问。
2. **开启抓取**：
   - 打开软件后，点击左上角“开启抓取”。
3. **嗅探资源**：
   - 打开要捕获的资源来源，如：微信视频号、网页、小程序、短视频平台等。
4. **下载与管理**：
   - 软件首页列表中会自动显示捕获到的资源。
   - 可直接点击“下载”或在“预览”窗口中边看边下。
   - 下载完成后，点击保存路径旁的文件夹图标，可直接**打开所在目录并自动高亮选中该文件**。

---

!> **Windows 注意事项**：若安全软件拦截，请点击允许；点击右上角关闭按钮默认缩小至**右下角托盘**。  
!> **macOS 注意事项**：如果无法正常拦截，请在系统设置中检查并允许网络代理与防火墙权限。
